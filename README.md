# .github

This repository manages the public GitHub organization profile and shared community defaults for the **Climate Intelligence CoP**.

## Organization Profile

The public organization profile is maintained in:

- `profile/README.md`

GitHub uses that file to display the welcome content on the Climate Intelligence CoP organization homepage.

## Future Defaults

This repository can also be used to store shared community files such as:

- `CONTRIBUTING.md`
- `CODE_OF_CONDUCT.md`
- Issue templates
- Pull request templates
- Funding or security policy files, if needed later
